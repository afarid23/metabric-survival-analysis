
# METABRIC Breast Cancer Analysis

An independent Python data analysis project exploring tumor grade and overall survival by estrogen receptor (ER) status in the METABRIC breast cancer cohort.

## Research Questions
- How does tumor grade differ by ER status?
- How does estimated overall survival compare between ER-positive and ER-negative patients?

## Methods
- Data cleaning and validation using pandas
- Merging patient and tumor sample data
- Descriptive statistics and visualizations
- Kaplan–Meier survival analysis
- Log-rank test

## Tools
Python, pandas, matplotlib, lifelines

## Data Source
METABRIC breast cancer study, accessed through cBioPortal.

## Limitations
This is an exploratory analysis using observational data. Survival comparisons are unadjusted and should not be interpreted as causal findings.
